# ArcDoodle

> ArcDoodle is a browser-based drawing application
> imagined and created by Bruce Johnson (aka my dad) with ChatGPT.

[Click here to open the application](https://denisecase.github.io/ArcDoodle/)

## About

ArcDoodle runs entirely in the browser from a single HTML file.

## GitHub Repository Settings

In the GitHub repository, go to
More (as needed) /
**Settings (far right)** /
Pages.

- Set Source to **Deploy from a branch**
- Set Branch to **main**
- Set Folder to **/(root)**
- Click **Save**.
