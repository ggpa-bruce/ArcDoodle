ArcDoodle

ArcDoodle is a simple drawing program that creates curves from a series of circular arcs that blend smoothly together.

Starting with dots

Click in the drawing area to place two or more dots. Select Define Angle from the menu. Move the cursor around the first dot to see the possible curves through the dots. Click to set the initial angle.

Continue clicking to add dots to the curve.

Starting with an angle

Select Define Angle before placing any dots. Click to set the initial dot. Move the cursor to choose the initial direction, then click to set the angle.

Move the cursor to preview the first arc. Click to set the next dot, and continue clicking to extend the curve.

Ending a curve

Press Return or Enter. The completed curve remains on the sheet and a new curve starts automatically.

Menu

Undo Last Define Dot removes the most recently defined dot.

Undo Last Define Angle removes the initial angle.

Grid: None / Rectangular / Triangular selects the drawing grid. Dots snap to grid points. The initial angle does not snap to the grid.

New Sheet clears the drawing area.

Use a computer screen capture to save a drawing.

Some interesting shapes

Two dots followed by a third dot at the same location as the first forms a circle.

Three dots followed by a fourth dot at the first dot will generally produce a cusp. A particular initial angle can smooth the cusp.

Four dots followed by a fifth dot at the first dot will generally produce a cusp that cannot be removed by changing the initial angle.
